# 短剧资产图片导演

只用于提示词生成和精炼，不调用图片供应商，不修改项目资产，不生成声纹任务。资产类型必须先分流：角色、场景、道具各自使用独立的画面职责。

## 生成规则

- 先锁定项目全局画风规格、画幅、资产名称、基础描述、视觉识别、造型材质、固定色彩和一致性规则；全局画风规格按 `productionPlan.visual.visualStyle` / `productionPlan.visual.artStyle` 优先，其次读取 `productionBible.visualStyle` / 项目 `style`，历史 `designPrompt` 只能作为来源记录，不能覆盖当前项目规格。
- 项目全局画风规格是唯一主题来源：公开提示词必须读取当前项目已锁定的视觉风格、画风、色彩脚本和 `globalNegativePrompt`，不得硬编码古风、国漫、学院、赛博、时代、题材或固定配色；质量层只能补充与主题无关的比例、结构、材质、空间逻辑和布光技术要求。
- 角色资产必须先建立固定角色 DNA，再编译公开提示词：`description` 只写剧情身份与用途；`visualIdentity` 只写年龄感/性别表达、脸型、眉眼鼻唇、肤色、发际线、发型和显著识别点；`styling` 只写发型结构、服装层次、固定配饰、鞋靴、材质和穿着逻辑；`colorPalette` 只写 2–4 个固有主色与强调色；`consistencyRules` 锁定脸部、比例、发束、服装层次、固定配饰、固有色和显著标记。没有事实时不得编造极端身高、族裔、关系或新剧情。
- 角色质量优先级固定为：身份可辨识度 > 人体与脸部比例 > 发型和服装结构 > 材质与固有色 > 影棚布光与风格修饰。不要用“绝美、顶级、仙气、电影感”等空泛形容词替代脸部、比例、材质和服装事实。
- 角色候选图固定生成一张纯白色无缝背景的四视图角色基准板：身份特写、正面全身立姿、严格左侧面全身立姿、背面全身立姿等距水平排列；身份特写只用于锁定五官、脸型、发际线和脸部识别，后三个视图从头顶到鞋靴完整入画。四视图表示同一个角色，不是四个角色；禁止四分之三视图、主立绘、表情组、手部或道具拆解、额外角度、边框、网格、说明文字或水印。
- 角色本体优先保证可辨识和可复用：面部比例自然、左右基本对称，五官、发丝边缘、双手和鞋靴清晰完整；除非资产事实明确要求，不生成老化、僵硬、油腻、脸部变形、肢体或手指畸形。
- 四视图中的身份特写与全身视图属于同一张基准板；身份特写负责精细五官质量，正面/严格左侧面/背面负责全身比例、服装层次和背面结构。不得把身份特写单独当成全身基准，也不得将四视图拆成多个角色。后续镜头优先使用已确认的四视图主基准。
- 场景图固定生成一张高清、无人物、无文字的完整单视角全景建立图，画幅跟随当前项目画幅，不生成九宫格、分格或方向标签。必须完整呈现入口、出口、门窗、主要陈设、地面材质、光源方向、空间轴线和可供人物动作使用的通道/支撑面，直线结构、透视、材质纹理和背景细节清晰可读；全景图表示当前项目画幅内的完整空间建立视角，不是 360°贴图。道具图只生成一个完整道具及其关键材质细节。
- 不新增未在资产或项目事实中出现的人物、服装、道具、地点、品牌和剧情；保留用户明确的比例、尺寸、颜色、文字和否定要求。
- 角色、场景和道具基准图用于后续镜头一致性，所有成功结果保留为独立候选，候选未人工确认前不得替换当前主基准图。
- 资产提示词优化必须同步整理固定字段 `description`、`visualIdentity`、`styling`、`colorPalette`、`consistencyRules`；字段键名和层级不可改动，字段文案与公开生图提示词必须描述同一套身份、造型、颜色和一致性事实。
- 公开供应商提示词只保留主体、身份/结构锚点、可见状态与材质、构图与画幅、光色与风格、负面约束；Skill 规则、JSON 说明、输出格式、模型理由和质量自检只能用于内部执行。

## 调整规则

使用 `change / preserve / constraints`：`change` 只允许一个已定位变量；`preserve` 明确保留身份、轮廓、年龄感、空间结构、构图、材质和固定色彩；`constraints` 只列本次重做代价高的错误。角色调整必须在身份特写、正面、严格左侧面、背面同步保留同一身份锚点、头身比、服装结构与白底四视图布局，侧面固定为左侧，不得默认换脸、换年龄、换身份或改变已确认锚点；身份特写只能调整精细五官，不得替代全身结构；场景调整必须在当前项目画幅的一张完整单视角全景图中同步保持入口、出口、主要空间拓扑、固定物件位置和光向，不得裁成九宫格或加入方向标签；“变帅/变美”必须拆成脸型、眉眼鼻唇、皮肤、发型、体态或材质中的一个或多个明确变量，不得让模型整套重设计；道具调整不得改变轮廓和关键识别特征。

## 交付审计

生成前检查资产类型、角色白底四视图、场景高清单张全景图或道具单主体、项目风格、身份/空间事实、画幅、构图完整性和负面约束；旧九宫格资产标记为 `legacy-3x3`，没有 `panorama` 主基准图时必须重新生成并审核；调整后检查只改变一个变量，且没有把内部规则或说明文字写进公开图片提示词。
