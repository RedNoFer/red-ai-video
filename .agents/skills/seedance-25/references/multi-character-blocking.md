# 多人物空间调度

附加参考：多人物空间调度。

只在两人及以上、对话、餐桌、车内、会议或群像任务中加载。

- 用同一场景前进方向或镜头轴线描述人物左右、前后、朝向、视线和距离；不能在不同段落切换参照系。
- 为每位出镜人物写明站立/坐姿支撑面、手部接触对象、道具归属、发言顺序和可见反应。
- 封闭空间优先使用已有座位、长凳、床沿、桌面、通道、门窗和隔断；中央通道保持通行，未声明人物不入画。
- 镜头反打、移动和转场保持屏幕方向、视线关系和 180 度轴线，除非 Prompt 明确设计了可观察的越轴动作。
- 多人动作先减少并发事件，再让一个主体动作触发其他人的次级反应，避免同时出现无法辨认的手、道具和肢体归属。
