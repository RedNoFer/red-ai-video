# 失败诊断

先按第一个失败层定位，不要一次重写全部提示词：

1. 身份漂移：收紧唯一身份来源、服装、体型和道具归属。
2. 参考串绑：拆分素材职责和作用范围，补充禁止继承项。
3. 构图错误：固定景别、机位、屏幕方向和主体位置。
4. 动作错误：补齐准备、接触/受力、结果和恢复的因果顺序。
5. 物理错误：补足支撑面、接触点、距离、遮挡和空间通道。
6. 时间错误：合并过密事件，使每段终点成为下一段起点。
7. 音频错误：明确对白、环境声、音乐、静音和字幕之间的优先级。
8. 连续性错误：只使用当前已验收的边界状态，不引用旧任务或未确认素材。

诊断时先保留已经通过验收的身份、服装、资产、空间轴线、光向和声音；然后只改失败层的一项变量。示例结构、参考视频和角色素材出现冲突时，优先修正职责和作用范围，而不是追加更多泛化否定词。

每次返修只改变一个已定位变量；保留通过验收的参考图、角色状态、空间轴线和声音规则。
