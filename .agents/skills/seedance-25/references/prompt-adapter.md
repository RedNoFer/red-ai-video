# Seedance 2.5 视频提示词适配器 1.4.2

## 职责

小墨 Skill 6.3 负责导演判断：剧情节拍、表演、空间调度、摄影、声音与镜头切换。此适配器只把已确认事实整理成 Seedance 2.5 易读的最终公开正文。时长、画幅、清晰度、参考素材职责、连续性和 QC 由制作包结构字段维护；门禁状态/证据、帧数/切数、减切原因和修订状态只进入结构化 QC，不得进入公开正文。若 authoring 自检发现混入，须在交付前修正制作包源稿；应用层原样保存正文，不追加统一视觉合同、不清洗正文，也不从 `framePlan` 重建或改写正文。

## 唯一正文结构

按以下顺序直接写自然语言，不加包装标题：

1. 以“开场时，……”开头，交代场景、人物入口、当前站位、支撑、接触、持物和轴线等本片段入口事实。
2. 只在开场没有包含所需基调时，追加一段视觉描述。视觉基调全篇最多出现一次；若开场已有，不再补充统一视觉。
3. 若本镜确有绑定素材，写一次 `参考图片：`，按实际绑定顺序列出真实 alias 和用途。未绑定素材不得编造 alias。角色素材绑定处只写一次四视图约束：`每张角色资产图均展示同一个人的不同观察角度，仅参考面容、体型、服装和配饰，不继承白底、排版或图中身体投影的数量。保证人物唯一性，每个角色在世界空间中仅有一人。`这条规则按每位角色分别理解；角色图中的多视角/身体投影不是场景中的额外人物。
4. 有稳定角色音色时，紧接参考图片清单写 `角色音色：`，并在首个时间段或 `Cut to：` 前结束；没有图片引用时，也放在首个动作段之前。只引用已配置音色；已确认配音音频时引用真实音频素材，不额外复制音色描述或伪造 alias、地址和 voiceId。
5. 从 `00.0` 开始，使用连续自然时间段覆盖整个逻辑片段。每段写摄影、可见动作因果、表演、完整原句对白和本段声音；对白全文仅出现一次。每段说明“谁做什么、因为什么、可见结果、声音锚点”。时间段数不必等于 `framePlan.frames[]` 数量。
6. 内部硬切在公开视频中用单独一行 `Cut to：起秒–止秒，……` 描述切后画面的实际范围，首镜也标出自己的范围；逐一与真实帧段边界对应，连续无重叠、覆盖完整片长。一个公开时间段可容纳多个明确计时的镜头，跨切长句只按原发声窗口写一次。切换类型、触发、新机位、切后主运镜、信息目的和动作/轴线承接写在切后帧 `transitionPrompt`，不写机器字段或 QC 话术。
7. 以“结束时，……”交代最后的世界位置、姿态、支撑、持有人、关键物件和环境结果。稳定角色音色不得追加在提示词末尾或写成泛化 `声音：` 结尾。

每段用完整自然句表达；移动写出触发、路径/受力和到达结果。每个公开视频提示词独立提交，入口连续性必须在当前开场写全。禁止依赖其他镜头、历史提示词、项目/对话上下文或内部 ID。

### 公开空间描述与去冗余规则

- 公开入口是当前片段的最小可执行空间说明，不是 `entryState` 的逐字段转写。以当前场景的固定锚点定位实际出镜人物，写清相对位置、必要支撑、关键持物与摄影轴线；不依赖历史提示词，不把屏幕左右当作不变的世界坐标。
- 普通站立不逐人重复“站姿、双脚接地支撑”；共用位置或支撑可合并表达。受伤、坐卧、蹲姿、左右手、接触受力和持有人变化等特殊事实须保留，不得为缩短文字虚构新站位、距离、朝向或动作。
- 公开道具只写当前可见、参与动作、决定揭示/遮挡/交接或易生成错误的必要状态。未取出的盒内物、收起的文书和多封未启用信件可按共同容器/状态合并；个人差异及全量库存留在结构化状态和覆盖审计，不能删除。照片、屏幕人物与录音声源须明确媒介，不得写成现场人物。
- 过程只写局部变化，按触发→动作/路径或接触→可见结果→声音组织；同一事实不在开场、逐切正文与结束反复粘贴。摄影机位、一个主运镜及观众要看清的内容合成一句，不重复“镜头对准”“让观众看清”或另加解释同义句。每个真实切镜仍须保留可辨的主体与信息变化。
- 结束说明最终位置、持有人及不可逆变化；未改变的人物位置、支撑和物件可在本条提示词内合并确认，不复写完整入口清单。合并只引用本条已经写明的事实，不能用“承接上一镜、同上”省略独立入口。结束事实不得与入口或片内已发生动作冲突。
- 编写时先去除库存罗列、正常物理状态套话、重复风格/音色/摄影目的和QC字段，再统计完整 `videoPrompt` 的Unicode字符数（含标点、空白、开场、结束和实际声音说明）。以2000以内为目标，2500仅提醒；超过时须记录逐片长度与未能继续压缩的具体原因，不能先输出冗长台账再依靠导入器截断或重写。
- 压缩前后逐片比较：原句发声内容/说话人/实际次数/顺序/时间窗、逻辑片段数量和时长、真实帧及内部切镜边界、必要动作因果与空间/道具特殊状态。不得靠删原句、改语速、减切、拆并逻辑片段或笼统“保持一致”满足长度目标。完整连续性状态和审计证据保留，公开段数与内部帧数继续独立。

## 禁止项与压缩

禁止 `参数`、`公共总规范`、`时间轴`、`收尾`、`台词`、`人声`、`音效` 等包装标题；禁止重复追加统一视觉合同、重复台词、字幕/转写/对白字卡、画面说明文字、未绑定 alias、镜头数据库编号、URL、编辑器元数据、未声明参数串、内部切镜统计和 QC 文案。公共风格只在正文开场处按需描述；局部声音写在实际发生的自然时间段，稳定角色音色紧跟参考图片清单。

完整正文以 2000 个 Unicode 字符以内为目标，2500 为提醒线。超过时仅提示压缩重复信息；不得阻断、截断或拆分逻辑片段，不删剧情动作、完整对白、表演、声音锚点与连续性事实。

只有当前 `productionLock.internalCutPolicy` 明确为 `dense-30s` 时，30 秒逻辑片段才要求 8–11 个真实帧段、7–10 次实际 `type=硬切`。少切例外写在结构化 QC，记录理由、实际帧/切数量和修订状态，不放进公开视频正文。

用户明确要求更严格的硬切范围时，同时满足当前帧数契约；要求8–11次硬切且最多11帧时，采用9–11帧、8–10次真实硬切。逐切检查切前触发、切后信息增量、动作与视线承接、空间与道具连续、揭示先于反应；只换景别重复同一事实不能用于凑数，跳切和换场不计作硬切。

## 剧情容量与角色视角

- 30秒的职责来自原文事实、自然对白、选择与动作结果；不把看纸、装袋、停笔或重复确认拆成独立长段，也不按硬切数量反推剧情时长。静默须有可验收的等待对象和结束变化，不能以人物原位或物件不动证明内容充实。
- 能看见的事实优先交给画面；心理独白只表达本人记忆、疑虑、动机或未说出口的判断，沿用本人稳定音色，不逐项念动作和库存。用户要求取消第三方旁白时，不得恢复外部讲解者。
- 原文间接引述的公开陈述必须保留对同伴发声的属性与知情顺序；仅在用户明确授权后，才可忠于原意改为第一人称现场陈述，并在对白审计中与原文直接引语分开登记。不得私有化公开承认，也不得补入新信息。
- 发声窗口、公开视频与内部帧段按真实时间范围对照；句末已收口的后续帧不能再次发声。先出现足以支持判断的可见证据，再安排相应结论。明确标为完整播放的源录音/影像必须保留实际播放长度。
- 本适配器不保留具体剧情的30秒示例。直接依据本轮源文和已有资产按上述自然段结构创作，避免例文人物、物件和情节污染。
