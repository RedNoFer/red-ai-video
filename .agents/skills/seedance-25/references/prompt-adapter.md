# Seedance 2.5 视频提示词适配器 1.4.0

## 职责

小墨 Skill 6.3 负责导演判断：剧情节拍、表演、空间调度、摄影、声音与镜头切换。此适配器只把已确认事实整理成 Seedance 2.5 易读的最终公开正文。时长、画幅、清晰度、参考素材职责、连续性和 QC 由制作包结构字段维护；门禁状态/证据、帧数/切数、减切原因和修订状态只进入结构化 QC，不得进入公开正文。若 authoring 自检发现混入，须在交付前修正制作包源稿；应用层原样保存正文，不追加统一视觉合同、不清洗正文，也不从 `framePlan` 重建或改写正文。

## 唯一正文结构

按以下顺序直接写自然语言，不加包装标题：

1. 以“开场时，……”开头，交代场景、人物入口、当前站位、支撑、接触、持物和轴线等本片段入口事实。
2. 只在开场没有包含所需基调时，追加一段视觉描述。视觉基调全篇最多出现一次；若开场已有，不再补充统一视觉。
3. 若本镜确有绑定素材，写一次 `参考图片：`，按实际绑定顺序列出真实 alias 和用途。未绑定素材不得编造 alias。角色素材绑定处只写一次四视图约束：`每张角色资产图均展示同一个人的不同观察角度，仅参考面容、体型、服装和配饰，不继承白底、排版或图中身体投影的数量。保证人物唯一性，每个角色在世界空间中仅有一人。`这条规则按每位角色分别理解；角色图中的多视角/身体投影不是场景中的额外人物。
4. 从 `00.0` 开始，使用连续自然时间段覆盖整个逻辑片段。每段写摄影、可见动作因果、表演、完整原句对白和本段声音；对白全文仅出现一次。每段说明“谁做什么、因为什么、可见结果、声音锚点”。时间段数不必等于 `framePlan.frames[]` 数量。
5. 内部硬切在公开视频中用单独一行 `Cut to：` 描述切后画面。事件时间、切换类型、触发、新机位、切后主运镜、信息目的和动作/轴线承接写在切后帧 `transitionPrompt`，不写机器字段或 QC 话术。
6. 以“结束时，……”交代最后的世界位置、姿态、支撑、持有人、关键物件和环境结果。可选末尾 `声音：` 只写稳定角色音色，不重复当句情绪、对白和局部音效。

每段用完整自然句表达；移动写出触发、路径/受力和到达结果。每个公开视频提示词独立提交，入口连续性必须在当前开场写全。禁止依赖其他镜头、历史提示词、项目/对话上下文或内部 ID。

## 禁止项与压缩

禁止 `参数`、`公共总规范`、`时间轴`、`收尾`、`台词`、`人声`、`音效` 等包装标题；禁止重复追加统一视觉合同、重复台词、字幕/转写/对白字卡、画面说明文字、未绑定 alias、镜头数据库编号、URL、编辑器元数据、未声明参数串、内部切镜统计和 QC 文案。公共风格只在正文开场处按需描述，声音只在实际发生的自然时间段和可选的末尾稳定音色句中描述。

完整正文以 2000 个 Unicode 字符以内为目标，2500 为提醒线。超过时仅提示压缩重复信息；不得阻断、截断或拆分逻辑片段，不删剧情动作、完整对白、表演、声音锚点与连续性事实。

只有当前 `productionLock.internalCutPolicy` 明确为 `dense-30s` 时，30 秒逻辑片段才要求 8–11 个真实帧段、7–10 次实际 `type=硬切`。少切例外写在结构化 QC，记录理由、实际帧/切数量和修订状态，不放进公开视频正文。

## 示例

```text
开场时，阿泽沿柏油路从画面左侧走向成都318零公里路牌下的长椅，左腕旧黑手绳露出；椅面有五只纸盒，越野车停在右侧。晨光从道路左侧照亮人物和纸面，晨雾只留在背景。

参考图片：
@图片1：场景「成都318零公里」
@图片2：角色「阿泽」
@图片3：角色「苏晚」
@图片4：角色「老杨」
@图片5：角色「许棠」
@图片6：角色「小林」
@图片7：道具「五人延迟寄送纸盒包裹」
@图片8：道具「成都至拉萨古地图」
@图片9：道具「五人同班次车票」
@图片10：道具「林澈教过的黑绳结」
@图片11：道具「阿泽旧黑手绳」
以上角色素材分别对应不同角色；每张角色资产图均展示同一个人的不同观察角度，仅参考面容、体型、服装和配饰，不继承白底、排版或图中身体投影的数量。保证人物唯一性，每个角色在世界空间中仅有一人。

00.0–04.0秒，道路侧固定全景，阿泽走到椅左前，袖口随步伐退开露出旧黑手绳；苏晚从椅右端靠近，看清绳结后停步，双脚稳稳落地。鞋底压过柏油，衣袖擦过手腕。
04.0–08.0秒，Cut to：椅前双人中景，苏晚指向包裹问：“你也收到这个？”阿泽抬眼回答：“看来不止我一个。”半秒停顿中两人互看，远车声压低，近处对白清晰。
08.0–12.0秒，Cut to：道路侧中全景，老杨、许棠和小林从车后通道走到车头；五人各自把一个纸盒放到地面后才松手，小林蹲下撕开纸壳，裂口露出旧物。
12.0–16.0秒，Cut to：小林右侧手脸近景，他把车票和地图放在纸壳上，右手托起旧电池，拇指停在接点后抬眼说：“这东西……我四年前见过。”迟疑后吸气，纸片轻擦。
16.0–20.0秒，Cut to：车头右侧许棠近景，她双手提起黑绳，指腹捏住结扣，认出后嘴角收紧、目光仍落在绳结上，说：“林澈教过我们这个结。”晨光照出湿黑纤维。
20.0–24.0秒，Cut to：道路侧俯视手部，五只手依次把地图碎片推齐在纸壳上；苏晚右指沿路线划过九个银灰标记，停在末端，说：“三千国道，九道关卡。”矿物线只反射晨光。
24.0–27.0秒，Cut to：纸壳左缘中近景，老杨蹲在阿泽对面读完字条，垂眼说：“至拉萨，可得解脱。”阿泽伸手取最后一张纸。
27.0–30.0秒，Cut to：阿泽肩侧俯视手部特写，他翻到纸背，旧手绳贴住纸边；看见已有笔迹后指尖停住，其余四人的手退出纸面，纸张翻动后阿泽短吸气。
结束时，五人围在车头前，地图留在地面纸壳上；阿泽握翻面的字条，许棠握黑绳，小林持旧电池，五人位置与支撑保持连贯。
声音：对白使用对应角色已登记的稳定音色，紧张不变声；实际对白清晰居前，环境声和拟音在发声时压低。
```

示例只展示结构。实际 `@图片` alias、镜头动作、对白和结尾状态必须来自当前素材绑定与源文；每个 `Cut to：` 必须有对应切后帧 `transitionPrompt` 证据。
