## 一、项目总览

- 集名：《无灵压的旅人》
- 小说章节：《阿佐雷斯的铸剑师》
- 类型：魔法学院、史诗奇幻、悬疑、拟亲情关系
- 核心冲突：两个几乎没有灵压的 Mahadel 新生进入受皇家法师严密监视的阿佐雷斯，他们隐藏的力量与 Karin 的断剑同时引起了某个古老存在的注意。
- 本集情绪：熟悉的互怼与温暖同行，逐渐被监视、失控和远古记忆侵入。
- 情绪曲线：EC2 悬疑五阶段，平静 → 不安 → 紧张 → 爆发 → 反转
- 色彩叙事：CN3 悬疑逼近，雾蓝灰 → 暗紫红 → 短暂银白爆发 → 炉火琥珀 → 冷紫黑
- 视觉风格：VS14 中世纪史诗的学院奇幻变体；宏大空间与克制人物近景并重，不使用现代元素或科幻 UI。
- 叙事主题：信任不是毫无保留，而是在知道对方有所隐瞒时仍选择并肩。

### 编剧结构卡

- 系列宏观结构：NS9 英雄之旅。本集完成“平凡世界、冒险召唤、跨越门槛、遇见导师”的前四步。
- 本集结构：NS4 双线叙事。A线是前往阿佐雷斯修剑；B线是黑湖、倒塔、四只手组成的记忆碎片，两线在奥伦的铁砧前汇合。
- 四幕：起 0-30秒，记忆钩子与搭档关系；承 30-75秒，装备失灵与城门盘查；转 75-120秒，力量暴露、被监视；合 120-180秒，进入铸剑铺并得到危险答案。
- 本集戏剧问题：断剑是被打断，还是在主动拒绝某种东西？
- 本集回答：它在“拒绝保持完整”。
- 结尾新问题：谁曾带着同一把剑来过，木匣为什么记得 Karin？
- Karin 外在目标是修剑，内在需求是承认异常已超出他的控制；Rifa 外在目标是保护 Karin，内在需求是尊重他面对真相的选择。
- 关系弧：互怼掩饰担忧 → 无言配合暴露力量 → Rifa 抓住 Karin → 两人的信任本身成为断剑识别 Karin 的媒介。

### 9:16 竖屏导演规则

- 人物关系采用前后景纵深、上下层级和门框构图，避免横向摊开多人。
- 城门双塔、阿佐雷斯坡城、倒悬塔和铸剑铺烟囱作为纵向视觉母题。
- 角色头顶与底部字幕预留安全区，关键道具放在中下三分之一，不贴屏幕边缘。
- 全案板与场景卡也使用9:16纵版模块，不把横版模板简单压窄。
- Ras、Ref 第一集不出镜；记忆中的另外三人只表现为手与不可辨识轮廓。

## 二、原创第一章

### 第一章：阿佐雷斯的铸剑师

阿佐雷斯的声音是从屋顶上落下来的。

铁锤敲击钢坯，铜铃在风里相撞，驮兽的蹄声沿着七层石街一圈圈向上攀升。商贩的叫卖被拱桥截断，又从更高的街巷里折回来。Karin 仰头时，只看见一片被塔楼、晾索和悬空水渠切割得支离破碎的天空。

Eda 没有这样的声音。Eda 的清晨通常只有风穿过麦穗，或者 Rifa 在窗外叫他起床。

“你再看下去，”Rifa 说，“我们天黑前也找不到店。”

Karin 收回目光，险些撞上一辆满载蓝玻璃瓶的手推车。他侧身避让，背后的断剑却磕上车沿，发出一声令人牙酸的轻响。

他立刻扶住剑鞘。

Rifa 看见了，却没有笑他。“还疼？”

“剑不会疼。”

“我问的是你。”

Karin 把手从剑柄上拿开。“那也不会。”

Rifa 嗤了一声，继续往前。她走得比平时快，斗篷下摆扫过潮湿的石阶。城门盘查已经结束了一刻钟，她肩背却仍绷得很直。Karin 知道她在听，听身后的脚步，听屋檐上的风，听那些因他们释放力量而短暂停止、如今又重新流动的城市杂音。

他们没有再提检查官的脸色。

也没有提那一瞬间，周围空气像是忘记了如何呼吸。

皇家结界悬在城市上空，肉眼看不见，只有经过路口的银色界碑时，Karin 才能感觉到皮肤上传来细微刺痛。那股力量正一遍遍扫过他的身体，试图确认一个不存在的灵压。

他腰间的护符忽然闪了一下，随即熄灭。

“第几个了？”Rifa 没回头。

“今天？”

“十八岁以后。”

Karin 想了想。“护符三个，照明石两个，暖炉芯一个。还有学院发的定位针。”

“定位针不是坏了。它只是每次指向你。”

“这听上去更糟。”

“本来就更糟。”

Rifa 在一条狭窄坡道前停住。坡道夹在两栋向外倾斜的石屋之间，尽头挂着一块深色木牌。木牌上没有剑，也没有铁砧，只有一条用银线嵌出的细长裂痕。

裂痕下方刻着店名：Edia Knight。

Karin 看了看门，又看向 Rifa。“你确定这是铸剑铺？”

“推荐信上写的是这里。”

“这更像一家专门替贵族保管秘密的地方。”

“阿佐雷斯的铸剑师大概两样都做。”

门没有把手。

Karin抬手叩门，指节还未碰上木板，腰后的断剑先震了一下。

不是金属受撞后的颤动。那感觉更像某种睡得太久的东西，在鞘中翻了个身。

Rifa 的手立刻按住短刃。“你做了什么？”

“我还没碰门。”

木牌上的银色裂痕缓慢亮起。光从上向下游走，最后停在 Karin 的剑鞘高度。

门内传来三次锤击。

第一声沉重，第二声短促，第三声像从很远的地下传来。

门向内滑开。

热浪裹着煤烟与金属气味扑面而来。铺子比外表深得多，墙上没有成排出售的刀剑，只有空钩、封闭的木匣和一座占据半个房间的黑色炉膛。炉火并不明亮，暗红的焰心却照出了地面上层层交叠的圆环刻痕。

一个男人背对门口站在铁砧前。他头发灰白，左臂套着厚重护具，右手握着一柄没有锤头的锤柄。

“关门。”他说。

Rifa 没动。“先报名字。”

男人转过身。他的左眼蒙着旧皮革，右眼却异常清亮，先看 Rifa，再看 Karin，最后落在那把断剑上。

“奥伦·奈特。”他说，“这里最后一个还肯修学生剑的人。”

Karin 把 Mahadel 的推荐信放在柜台上。蜡封刚触到木面，便自行裂开。

奥伦没有看信。“剑拿出来。”

Karin 抽出断剑。

剑身在距护手一掌处折断，断口灰暗，没有新裂开的锋利光泽。奥伦用两根手指夹住剑脊，神情第一次发生变化。

“谁告诉你这是被打断的？”

“没人需要告诉我。”Karin 说，“我看着它断的。”

“你看见的是结果。”

奥伦将断剑平放在铁砧上。他没有点燃符文，也没有念咒，只把那柄无头锤的木柄轻轻贴上断口。

炉火骤然缩成一线。

屋内所有金属同时发出低鸣。

Karin 的护符、Rifa 的短刃、墙后看不见的锁链，甚至门外路人的腰扣，都在同一刻朝铁砧偏转。Karin胸口一紧，某段不属于他的景象从眼前掠过：黑色湖面，一座倒悬在水中的塔，以及四个人在雪里互相抓紧的手。

他只认出了其中一只手。

那是他的。

“Karin。”Rifa 抓住他的手腕。

幻象破碎。炉火恢复，金属低鸣也随之停止。

奥伦盯着两人交握的手，神色比刚才更沉。

“放开他。”

Rifa 没放。“为什么？”

“因为这把剑正在借你的记忆认他。”

Karin 觉得她的手指收紧了一瞬。

“剑不会记得人。”他说。

“普通的剑不会。”奥伦把无头锤柄放下，“普通的剑也不会在主人十八岁之后，开始让他身边所有魔法器具失灵。”

铺子里安静下来。

门外的阿佐雷斯依旧喧闹，仿佛隔着很深的水。

Rifa 先开口：“你知道原因。”

“我知道一个原因。”

“区别呢？”

“知道原因的人能给答案。只知道一个原因的人，通常只够活着发出警告。”

奥伦从铁砧下取出一只窄长木匣。匣盖上同样嵌着银色裂痕，只是裂痕中央多了四个极小的圆点。

他没有打开，而是推到 Karin 面前。

“你的剑不是断了。”

Karin望着他。

“它拒绝保持完整。”奥伦说，“而且你不是第一个把它带到这里的人。”

Rifa 的短刃出了半寸。

“上一个人是谁？”

奥伦没有回答。他看向天花板。那里悬着一面被烟熏黑的铜镜，镜中没有映出他们三个人，只映出城门高塔上一个披斗篷的身影。

那人也正透过镜子看着他们。

奥伦抬手熄灭炉火。

黑暗落下前，Karin 听见木匣里传出一句极轻的话。

不是声音，更像被某件东西记住太久的念头。

“你又来迟了。”

## 三、第一集文学剧本（编剧链重构版）

### 基础设定

- 片长：约3分钟；7场；12段×15秒；9:16竖屏。
- 表演方法：PM2梅斯纳反应优先。Karin与Rifa的关系由倾听、视线和走位呈现，不用解释性对白。

### 场1｜黑湖记忆｜时间不明｜0-15秒

黑湖没有波纹。倒悬在水下的高塔占满竖幅，塔尖正对Karin的倒影。雪地里，四只手彼此抓紧。Karin看不清另外三个人的脸，只看见自己掌心握着一截完整剑刃。

剑刃自行裂开。

记忆中的声音（耳语）：“你又来迟了。”

Karin猛然睁眼。

### 场2｜马车｜白日｜15-45秒

Karin的手仍扣在断剑上。Rifa没有追问，先等他的呼吸恢复。

Rifa：“又是那个梦？”

Karin：“只是路太颠。”

Rifa看一眼平整得过分的皇家道路：“当然。石头还学会道歉了。”

她把水囊推过去。Karin刚接住，腰间护符忽然闪烁后熄灭。

Rifa：“第几个？”

Karin：“今天？”

Rifa：“十八岁以后。”

Karin没有回答。车窗外，皇家结界已经逼近。

### 场3｜城门盘查｜午后｜45-75秒

马车穿过水波般的结界，高塔法师同时转头。检查官把黄铜探测器依次对准Karin与Rifa，指针死死停在零。

检查官：“没有灵压，却带着Mahadel的徽记。”

Rifa：“你可以说我们很有礼貌。”

检查官抬手，闸门锁链落下：“也可以说，你们在隐藏危险。”

Karin向前半步，挡住检查官看向Rifa的视线。

Karin：“我们只是来修一把剑。”

### 场4｜力量解封｜连续｜75-105秒

Rifa不看Karin的脸，只看他扣在断剑上的拇指。那是两人早已约定的信号。她走到与他完全并肩的位置。

两人同时松开封印的一线。

没有火焰，没有雷霆。声音先被抽空。旗帜停在风里，尘埃悬浮，结界向二人凹陷，探测器从内部裂开。

Karin先收力。Rifa慢半拍，确认他站稳才收回力量。

Karin（低声）：“这样够明显吗？”

检查官看见一年级徽记，放下手臂。闸门开启。高塔上，观察者转动四点银戒。

观察者（耳语）：“两个异类。可预言里，缺了两个名字。”

### 场5｜阿佐雷斯街巷｜下午｜105-120秒

城市沿竖向陡坡层层升高。Karin仰头看得出神，断剑撞上手推车，他立刻护住剑鞘。

Rifa：“还疼？”

Karin：“剑不会疼。”

Rifa放慢脚步，与他并肩：“我问的是你。”

Karin不回答，但没有把手从剑上移开。

### 场6｜Edia Knight门前｜傍晚｜120-135秒

坡道尽头，木牌上的银色裂痕与梦中剑刃的裂口完全相同。

Rifa：“你见过这个？”

Karin：“没有。”

他说得太快。抬起的手尚未碰门，断剑先在鞘中震动。门内传来三次锤击，木门自行开启。

奥伦在纵深尽头背对二人：“关门。把剑放到铁砧上。”

### 场7｜铸剑师的警告｜连续｜135-180秒

Rifa守在门与Karin之间，直到Karin主动走向铁砧才让开半步。

奥伦不看推荐信：“谁告诉你，它是被打断的？”

Karin：“我看着它断的。”

奥伦：“你看见的是结果。”

无头锤柄碰触断口。炉火缩成一线，店内金属全部朝铁砧偏转。

黑湖、倒塔、四只手。这一次，Karin看清其中一只手腕系着暗红细线。他转头看向Rifa的辫绳。Rifa立刻抓住他的手腕，幻象破碎。

奥伦：“别放开。剑正在借她的记忆认你。”

Rifa：“你知道它为什么断？”

奥伦取出带四点印记的木匣：“它不是断了。它在拒绝保持完整。”

他把木匣推向Karin：“而你，不是第一个带它来这里的人。”

铜镜中没有店内三人，只有高塔上的斗篷身影。Rifa的短刃滑出半寸。

Rifa：“上一个人是谁？”

奥伦熄灭炉火。黑暗中，木匣再次耳语：“你又来迟了。”

切黑。
