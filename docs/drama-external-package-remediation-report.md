# 外部 Agent 制作包整改与回归报告

本轮已落实外部 authoring 规范、只读检查、导入预览、合并保存及刷新回读的整改。保留制作包 v1、13 个固定章节和唯一嵌入 JSON，未新增正式包字段或数据库表。内部生成编排、供应商提交、视频时长拆段及成片混音不在本轮修改范围。

## 交付内容

- [制作包规范](drama-production-package-v1.md) 与[下载模板源](drama-production-package-v1-template.md)：补充完整来源读取、逐句声源和顺序、场次事实与知情、世界空间和道具归属、逻辑轴冻结、帧信息职责、观众顺序审阅及局部修订；保持一次完整修订上限。
- [字段合同](drama-production-package-v1-fields.md) 与[最小合法镜头示例](drama-production-package-v1-field-example.json)：明确锁定方案、发声记录、状态、表演和帧计划的嵌套类型。示例由真实导入器验证，只说明合同，保留修订 QC 和占位审计说明，不宣称生产合格。
- 导演 Skill `1.13.0`、图片 Skill `1.2.2`，统一角色白底板为身份特写＋正面、严格左侧面、背面全身；场景使用当前画幅高清单视角全景。图片、导演和 Seedance Skill 均纳入现有镜像同步机制，编译与镜像共用内容哈希算法。
- `web/scripts/check-drama-package.mjs`：读取制作包及可选源 TXT，复用项目解析器与现有 QC；不调用模型、不生成分镜、不改输入。报告保留作者 QC、检查范围、声源歧义和媒体未验收的缺口。提供源 TXT 时同时检查冻结来源哈希。
- 独立包预览、应用、保存及导出保留作者公开文字；不补对白、不追加声音指令、不按目标风格重编译。风格和质量冲突集中提醒，可确认后继续导入；结构、嵌套类型、非法运行字段和时间轴错误阻断。
- 合并保留固定资产和人工字段；保留人工执行稿时重新检查它与当前对白及帧计划是否相容。应用读取最新项目、检查 sourceHash 并保存导入前版本，覆盖预览期间自动保存的情况。
- 同帧 ID 的提示词、对白或入口状态变化后，现有图片及帧媒体保留，连续性证据进入待复核状态。重新导入修订包同样保留媒体；未标人工的旧自动执行稿清除，避免继续覆盖作者新稿。不自动重新生成。

## 检查命令与状态

```sh
pnpm --dir web run check:drama-package -- /绝对路径/制作包.md --source /绝对路径/源文.txt
pnpm --dir web run check:codex-skills
```

制作包检查退出码：`0` 表示当前文本检查无阻断项；`1` 表示输入或结构不可导入；`2` 表示结构可导入但存在质量修订项。导入成功不等于作者 QC 或媒体质量验收通过。未提供源文及无法识别归属的引文明确报告，不按零对白通过。

仅统计对齐真实帧边界的 `type=硬切`；匹配切、跳切与跨片段转场不计入。30 秒 dense-30s 保持 8–11 帧、7–10 次硬切。减切原因与修订状态同时报告，不改成 adaptive。逐对枚举相邻片段，缺边、无效引用、缺状态及换场/跳时依据分别报告。

正文核对覆盖章节、角色与场景清单、文学剧本、镜头时间码、对白、第十一章公开视频原稿及已填写章节归档。多人调度、递物接触、不可逆状态、信息揭示与回忆转换依然需要作者按导演规范审阅；工具的文本检查不能替代实际媒体和观众验收。
