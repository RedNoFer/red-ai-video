# v0.0.32 短剧完整提交提示词回归

本次修正镜头确认文本与上游输入不一致、参考图名称丢失、重复音色规则和图片数量约束未匹配实际模型的问题。

## 线上记录与根因

对目标项目的两个失败任务进行了按实体定向只读查询：每次实际选择 11 张固定资产图（1 个场景、5 个角色、5 个道具）；上游 `yinglingapi` / `dola-seedance2.5-30s` 明确返回最多 9 张。旧能力匹配遗漏 `dola-` 模型前缀，且没有独立模型配置时能力解析使用通用操作配置，最终按 30 秒通用预算放宽到 30 张。

提交链原先在确认后重新拼接图片、角色音色和素材一致性说明；实际参考图的具体名称没有进入这份追加文本，全部回退为通用标签。

## 当前行为

- 前后端共用实际参考图绑定构造器，按本次选中数组连续编号，写明角色、场景、道具或线索名称；取消和手动新增同步预览。
- 角色音色保留原音色事实或音频编号，公共对白约束只写一次。
- 文本框包含完整上游提示词，确认正文保存在运行快照；调度、视频任务路由及不鸣协议适配器不再补充正文，换行和首尾空白也保持原样。
- 更改引用只更新预览中的绑定段落；保留作者在其前后添加的正文。
- 删除短剧请求尾部隐式追加的素材一致性段落；其他工作台继续沿用其现有契约。
- 具体模型最大图片数通过既有预检 GET 供确认弹窗使用，服务端与任务入口继续校验；保留主分支视频质量检查仅作建议、任务不等待上一镜质检的更新。

## 验证

发布门禁：572 个测试文件通过、5 个按环境跳过，3394 项测试通过、12 项按环境跳过；ESLint、Prettier、类型检查、当前源码生产构建及 Standalone 完整性检查通过。所有变更文本严格 UTF-8 解码，未增加乱码标记。

浏览器：桌面、390px、430px 完整矩阵首轮 203 项通过、18 项按配置跳过；3 个新提交用例暴露测试配置未将九图能力写入自动派生模型的问题。修正夹具并断言保存后的能力，单独执行提交和预览回归，9 项全部通过，完整矩阵共 206 项有效用例完成验收。密集组合触发现有视频限流时按独立运行复核，没有增加延时、重试次数或放宽生产限流。

重点断言包括：

1. 九图可提交、十图本地拒绝，未创建上游任务。
2. 文本框、持久化快照、执行快照和实际 TCP 上游请求逐字相同。
3. 图片编号、资产名称、角色音色和实际图片数组一致，取消引用后编号连续。
4. 手动新增固定资产、原剧情绑定保护、刷新、用户末尾编辑与移动端布局。
5. 影灵与不鸣的完整正文不再被协议适配器追加文本；其他工作台相关回归继续通过。

本轮未调用真实付费图片、音色或视频生成。未配置隔离 PostgreSQL 测试库，相关环境条件用例按项目既有规则跳过。TODO 中的真实渠道、整集成片和运营治理验收仍保持待办；本轮没有把它们标为完成。
