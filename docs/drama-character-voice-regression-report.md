# 角色音色绑定回归报告

日期：2026-10-11。交付版本：v0.0.26。

制作包继续使用 v1、13 个章节及唯一嵌入 JSON，字段合同更新为 1.1.0。角色固定音色保存于 `assets.characters[].voiceProfile.timbrePrompt`，第五章角色卡展示同一文本；当句语气、停顿和情绪仍属于台词表演。

角色编辑器提供独立的“固定音色提示词”和“台词表演指令”。镜头确认页显示实际声音来源，并允许试听已绑定音频。运行时优先引用上传的角色音频，其次引用成功生成的角色试听；没有音频时加入固定音色提示词。所选角色资产和画外说话人使用同一绑定规则，多角色音频按实际提交顺序编号。

## 已验证的行为

- 制作包预览、应用、保存、序列化及刷新回读保留音色原文；导入保留已有角色音频、声纹 ID、倍速和人工配音字段。
- 导入不追加或改写作者公开视频正文；声音绑定只加入运行时执行请求，不增加台词、不复述样本、不改变对白窗口。
- 视频请求实际携带角色参考音频。上传音频优先于试听及文本；无音频采用文本。未选中的无对白角色不会被额外引用，画外说话人仍保留声音身份。
- 非字符串音色、非角色资产的音色对象，以及外部包中的运行时音频 URL、供应商声纹等字段会明确报错。
- 浏览器专项覆盖制作包导入、角色音色编辑保存、刷新恢复、音频上传及生成确认来源切换；桌面、390px 和 430px 均通过，音频控件不溢出视口。
- PostgreSQL 真实触发器下的保存回执、连续写入、刷新回读和旧版本拒绝通过，导入音色字段在回读后保持一致。
