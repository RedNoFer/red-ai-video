### 9:16 竖屏导演规则

- 主体优先：近景保留完整头顶、下巴、主要衣领和关键手部；双人镜头不要为了容纳背景而过度贴脸。
- 安全区：人物不要贴近上下左右边缘；为头顶、下巴、肩线和动作方向预留空间。
- 构图策略：优先单人中近景、过肩、前景/中景/后景叠层；多人关系无法清楚承载时拆成关系、反应和细节镜头。
- 场景锚点：每镜至少保留一个可辨识的门窗、桌面、通道、墙柱、座位或道具位置，避免竖屏像横版画面被裁切。
- 仅作建议：如果当前镜头可能裁脸、裁肩、裁手或人物过度靠边，在镜头结构卡和 QC 中标记风险，不自动阻止生成。

> 相邻段避免重复同一表情、手势、双人构图或镜头功能。切镜建议落在动作结果、完整短句、视线接住或反应成立之后。

### 运动物理检查

- 每镜仅保留一种相机运动、一种主体运动和一种环境运动。
- 连续帧按“建立场景 → 镜头/主体推进 → 关键动作 → 结果或反应/转场”拆分；动作 Prompt 写发生什么，静态帧 Prompt 写动作已经造成的可见结果。
- 时间段按实际动作节点和帧数连续分配，不预设固定秒数。静态帧也必须改变姿态、表情/视线、手部/道具或环境中的至少一项，不能只写氛围或重复同一句场景描述。
- 禁止使用“入口构图已建立”“动作展开”“关键变化”“结果状态”或“眉眼、呼吸、手部关系清晰可见”等通用模板句；`可见表演状态` 必须写当前节点具体的表情、视线、呼吸、手部或身体结果。
- 只保留身份、服装、道具材质、空间轴线和光向等必要连续性；减少“构图不变、主体稳定、情绪保持不变”等约束。
- 相邻镜头景别、机位、焦段或构图至少有一项产生真实变化；如果没有变化，说明为什么仍由同一镜头承担。
- 硬切必须有触发事件、新信息和承接关系；不要只写“硬切”或只更换焦段。
- 运镜应对应人物决定、视线变化、动作结果或压力升级；没有动机时建议使用锁定机位。
- 情绪重锤后建议安排反应、身体停顿、道具细节或留白，不连续复制同一个表情和手势。
- 9:16 近景检查头顶、下巴、衣领和关键手部；全景检查主体、空间锚点和动作方向是否可辨。
- 台词、站位、道具状态与剧情事实不一致时标记为提示，先修正事实再压缩提示词。
